# Security Policy

## Supported versions

Security fixes are provided for the latest published `gallery_picker_gdx_plus` minor release. Users should upgrade to the newest available patch release before reporting an issue.

| Version | Supported |
| --- | --- |
| 0.6.x | Yes |
| `gallery_picker` 0.5.x and earlier | No; use the maintained package |

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Send a private report to [contact@gurwinderdevx.com](mailto:contact@gurwinderdevx.com) or use [GitHub's private vulnerability reporting](https://github.com/47gurvinder/gallery_picker/security/advisories/new).

Include the affected version and platform, impact, reproduction steps or a proof of concept, and any suggested remediation. You should receive an acknowledgement within seven days. The maintainer will coordinate validation, remediation, release timing, and responsible disclosure with the reporter.

For non-security defects, use the public [issue tracker](https://github.com/47gurvinder/gallery_picker/issues).
